# CLI To-Do Application
A lightweight, in-memory command-line interface for task management built entirely in Python.

## Features
* **Add:** Append new tasks to the list.
* **View:** Display all current tasks with their corresponding index numbers.
* **Complete:** Safely remove a specific task by typing its exact name.
* **Quit:** Exit the application safely.

## Usage
Run the script via your terminal:
`python todo.py`
